# Third-party notices

## AprilTag WebAssembly

The application includes `apriltag_wasm.js` and `apriltag_wasm.wasm` copied from `arenaxr/apriltag-js-standalone` at commit `7a6ad7ddb3562031ab2deb0c5ac5faeb86df599c`. That distribution is derived from the AprilRobotics AprilTag C implementation and is used for tag36h11 detection.

The bundled BSD 3-Clause license text is available at `public/vendor/apriltag/LICENSE`. The detector assets are kept local so marker images never need to leave the device.

Users remain responsible for observing the attribution and reuse terms of the original datasets.
